# Retired data and RAG history

This archive preserves documentation and recorded experiment evidence from the
implementation retired on 13 November 2026. Statements, commands, ownership and
test counts describe their original dates. They are not the current workflow or
proof that the removed implementation is available. No runnable pipeline or
legacy source dataset is retained here. Embedded JSON evidence may describe
old records, source hashes and historical outputs; it is not an active corpus.

See the [reset record](../../data/cleanup-reset.md) and
[active data workflow](../../data/workflow.md). Model files and local historical
trial reports were retained separately; old corpora/indexes were deleted.
