# ADR-002: Baseline SLM

- Status: Proposed
- Date: 2026-10-22 (local draft)
- Author: Soulaiman; assigned reviewer Anas; no team acceptance claimed
- CDC reference: §23

## Context

S1-T03 needs an interchangeable No-RAG model runner and first Qwen/Phi runs. The
[inventory](../../datasets/MODELS.md) supplies candidates but no measured runtime
fit. The current local machine is a Ryzen 5 5625U with integrated Radeon graphics
and approximately 14 GiB RAM, distinct from Oussama's NVIDIA laptop assessment.
Anas's merged pilot is synthetic and development-only; independent review, a
frozen test split and faithfulness-judge validation remain incomplete.

## Options considered

| Candidate / path | Local investigation |
|---|---|
| Qwen2.5-1.5B-Instruct, publisher Q4_K_M GGUF | Smaller CPU development candidate; real generation and full-pilot attempt completed locally |
| Phi-4-mini-instruct, bartowski Q4_K_M GGUF conversion | Larger CPU comparison candidate; full local pilot completed; 13/14 contract-valid, with weak triage scores |
| Qwen 3B / SmolLM2 and alternate precisions | Inventory candidates; not downloaded or measured by this task |

Exact artifacts, runtime pins and procedure are in the [runner guide](../../ai/baseline/README.md).
The [local results note](../../ai/baseline/LOCAL_RESULTS.md) records completed runs and limits.
The GGUF revision and checksum identify the executed artifact; the conversion's
exact source checkpoint lineage has not been independently established. The
inspected current upstream HEAD must not be presented as proven conversion origin.

## Proposed decision

Keep both Qwen and Phi behind the same interface for the required comparison.
Use the local CPU/GGUF path for exploratory development on this machine; retain
model-specific embedded chat templates and record quantization explicitly. Do not
select a final quality winner from schema validity, one-pass timing, or the small
unreviewed synthetic pilot. Final baseline selection remains pending review of
measured results and the evaluation-readiness limitations.

This proposal does not choose the official benchmark environment (ADR-007), the
final serving architecture (ADR-005), a quantization winner, or artifact hosting.

## Consequences

The runner can be developed and tested without a GPU or model downloads in CI.
Local weights/runtime binaries and generated output remain ignored and unpushed.
CPU timing, community conversion provenance and the unfrozen dataset limit claims;
no FP16-versus-INT4 ablation, production-readiness or held-out performance is established.
API integration depends on agreement with Oussama's separately proposed interface.

## Evidence and approval

Local evidence is recorded in Soulaiman's [S1 journal](../sprints/sprint-01/README.md)
and ignored run directories referenced there. No S1-T03 PR, reviewer approval or
hosted-CI result exists. This ADR remains Proposed.
